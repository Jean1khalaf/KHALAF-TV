# Remote provider tab (browser version)

Browsers do not allow a remote device to create a new tab on the TV browser without a user gesture on the TV. In the provider fallback panel, click **Enable remote channel tab** once on the TV and allow pop-ups for the KHALAF TV site if prompted. This creates a named tab owned by KHALAF TV. Thereafter, selecting MTV/LBC/Al Jadeed/Al Hadath on the phone navigates that same tab; **Close provider tab** on the phone closes it. The ordinary **Open provider page** link remains available as a manual fallback.

This applies to the web version. The Windows Electron app uses its own managed provider window. The remote cannot close unrelated tabs that it did not create.
